# dsh-task-widget — Windows 桌面独立小组件（液态玻璃任务台）v0.5.0

聚合 DSH 全部会话/任务与进度，常驻桌面的原生玻璃小窗；任务完成推 Windows 系统通知。
**v0.5.0 是「真液态玻璃」里程碑**：放弃 0.4.0 的纯半透明，改为 **Win11 DWM 合成器级 Acrylic 真高斯模糊**。

## 核心特性

- **真·液态玻璃（v0.5.0 重点）**：Win11 走 `DWMWA_SYSTEMBACKDROP_TYPE=3`（Acrylic），由 DWM 合成器做
  真实高斯模糊——GPU 加速、零闪烁、自动处理多屏与 DPI，不再截屏背后桌面（0.4.0 的截屏方案已废弃）。
  顶部加 `SpecGlow` / `UsageGloss` 径向高光（光打在玻璃上的漫反射）。
  **Win10 无此能力，自动降级**为纯色半透明 + 顶部高光（视觉接近玻璃感但不模糊桌面）。
- **任务聚合**：运行中会话置顶、三点动画、完成/全部完成/后台任务完成系统通知（WinRT Toast + AUMID，回退托盘气泡）。
- **任务点击跳转**：点击任务卡 → 跳转到对应会话（SSE `pending` 事件 + `sessions.select`）。
- **工作区 / 项目区分**：项目名作主行，工作区名作暗色副行「工作区 · xxx」。
- **用量卡（独立卡片，接在主卡底部）**：
  - **本回合 Token**（主显示，来自宿主对 `turn/start`→`turn/end` 的增量追踪）+ **累计** 副标；
  - 取「最近更新的运行中会话」为主会话，用量卡标注「主会话 · 标题」；
  - 当前花费（¥，总额度−可用）、剩余 Token 量（容量−已用）、剩余额度（可用余额 ¥）；
  - 未配置 API Key 时显示「用量 · 未配置 API Key」+「未配置」，而非干瘪的 —。
  - 点击用量卡 → 打开 DSH 用量页（根 UI）。
- **运行中计时**：运行中任务显示「运行中 · 1m 23s」（基于会话更新时间，1s 滚动）。
- **位置**：四角预设（设置页选择）+ 拖动结束磁性吸附（≤48px 自动贴最近角落并持久化）。
- **用量卡开关**：设置页可关，关闭后小窗缩高（512→360），仅任务列表。
- **锁定**：右下角锁按钮（带按压缩放）；锁定后不可拖动。
- **透明度可调**：玻璃透明度（窗口整体不透明度 40–100）+ 卡片着色强度（40–100）。
- **深/浅色跟随系统**；崩溃自愈（连续 5 次快速崩溃熔断）；系统托盘图标作为通知来源、右键退出。

## 架构

```
宿主守护 (lib/index.js, 跑在 DSH 服务进程内)
  ├─ 数据收集：ctx.sessions / ctx.jobs / ctx.sessionProjections / 账户余额
  ├─ 注册 /dsh-task-widget 前缀路由（同源）
  │     /api/snapshot   完整快照（2s 轮询）
  │     /api/events     SSE 实时推送（snapshot / toast / pending）
  │     /api/ctl        显示/隐藏/配置/激活（小窗与设置页调用）
  └─ 派生 PowerShell + WPF 原生小窗 (widget/widget.ps1，零外部依赖)

客户端注入 (lib/client.js, __ModuleLoader__.load)
  ├─ 会话头部「任务小窗」开关按钮
  ├─ 设置页「任务小窗」区块（settings.section 槽 inject 注册）
  └─ 常驻 SSE 监听 → 小窗点击任务时跳转会话
```

## 设置（DSH 设置 → 任务小窗）

显示/隐藏开关、强调色 6 色板、玻璃透明度、卡片着色强度、**小窗位置（四角）**、**显示用量卡**，
以及「应用」按钮——外观改动点应用后才提交（带「已应用 / 有未应用的改动」提示）。

## 部署

1. 把 `dsh-task-widget`（或 dist/ 内容）注入 DSH：
   `dev_inject_plugin <路径>/dsh-task-widget-0.5.0`
2. 重载包：`dev_reload_package dsh-task-widget`
3. 小窗由宿主自动拉起（首次约 1.5s 后）。

> 校验：本包免编译，`bash scripts/build.sh` 仅做完整性校验（含 widget.ps1 的 UTF-8 BOM 检查）。
> **widget.ps1 必须保持 UTF-8 带 BOM**，否则 Windows PowerShell 5.1 按 ANSI 读会乱码崩溃。

## 已知限制 / 后续

- Acrylic 仅在 Win11（build ≥ 22000）生效；Win10 自动降级纯色。
- 用量卡点击打开的是 DSH 根 UI（用量页深链未知，暂用根地址）。
- 后续可选：SSE 合并为单通道、DSH 全屏时自动隐藏小窗。
